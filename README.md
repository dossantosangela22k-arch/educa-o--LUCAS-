
# 🚀 Aventuras do Lucas - Jogo Interativo de Leitura

Um aplicativo web simples, colorido e interativo desenvolvido especialmente para ajudar crianças pequenas (como o Lucas, de 5 anos) a aprenderem a ler através de histórias, associação visual de palavras e síntese de voz (áudio).

---

## 🎨 Características do Projeto

* **Visual Atraente e Colorido:** Design adaptado para o público infantil com cores vivas, fontes grandes e emojis.
* **Leitura com Voz (Text-to-Speech):** Utiliza a API nativa do navegador (`SpeechSynthesis`) para ler os textos em voz alta, de forma pausada e clara.
* **Totalmente Clicável e Intuitivo:** Botões grandes para facilitar o clique por crianças em dispositivos móveis ou computadores.
* **Progressão por Fases:** Desafios sequenciais que acompanham a evolução da criança (vogais, encontros vocálicos, sílabas simples e pequenas palavras).
* **Feedback Imediato:** Mensagens positivas ao acertar e incentivo imediato ao errar.
* **Sem Dependências Externas:** Feito em um único arquivo HTML, rodando diretamente no navegador sem necessidade de instalação de servidor.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura e marcação dos elementos do jogo.
* **CSS3:** Estilização responsiva, cores, grade de opções e efeitos nos botões.
* **JavaScript (ES6):** Lógica do jogo, troca de fases, verificação de respostas e integração com a API de síntese de voz do navegador.

---

## 🚀 Como Executar o Projeto

1. Baixe ou copie o arquivo `index.html` do repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno (Google Chrome, Microsoft Edge, Safari, Firefox, etc.).
3. Certifique-se de que o som do dispositivo esteja ligado para ouvir a leitura das histórias.

---

## 📅 Plano Pedagógico de 1 Mês

O jogo foi estruturado para ser utilizado diariamente (de 10 a 15 minutos por dia) seguindo a sequência:

1. **Semana 1:** Vogais e encontros vocálicos (`AU`, `EI`, `OI`, `MIAU`).
2. **Semana 2:** Sílabas simples e palavras curtas (`BOLA`, `CASA`).
3. **Semana 3:** Consolidação de palavras de 3 e 4 letras com apoio dos emojis (`SOL`, `LUA`).
4. **Semana 4:** Leitura completa das frases e desafio final do campeão.
